# SVARA — kênh phát hành

Repo này chỉ chứa **bản phát hành (.exe) của Bản chấm**, không chứa mã nguồn.

- Bản mới nhất: [Releases](../../releases/latest) → tải `SVARA-<phiên bản>.exe`
- Chạy trên Windows 10/11 (64-bit). File chạy thẳng, không cần cài.

## Dùng lần đầu

1. Tải `SVARA-<phiên bản>.exe` về một thư mục riêng (ví dụ `D:\SVARA\`) rồi mở.
2. Windows có thể hiện "Windows protected your PC" vì app chưa ký số: bấm **More info** → **Run anyway**.
3. Đăng nhập bằng **Tài khoản Second Brain** (email + mật khẩu). Tài khoản do label cấp, chưa có thì hỏi label.
4. Mở **Pack được giao** để nghe, góp ý, chấm điểm và gửi Feedback.

Mỗi Phiên bản kèm số SHA-256 của file trong ghi chú phát hành, để kiểm file tải về đúng là bản gốc.
